# Getting started with Binance-US-MCP

MCP server for Binance.US exchange - spot trading, wallet management, and US-specific features

## Install

```bash
npm install
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/Binance-US-MCP.git
cd Binance-US-MCP
```

Available commands:

| Command | Runs |
|---|---|
| `npm run start` | `node build/index.js` |
| `npm run dev` | `tsx watch src/index.ts` |
| `npm run build` | `tsc` |
| `npm run test` | `npx @modelcontextprotocol/inspector tsx src/index.ts` |
